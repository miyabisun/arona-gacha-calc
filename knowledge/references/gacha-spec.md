# ゲーム内事実(全てユーザー提供)

## 確率

- フェス限定ガチャの星3は 3%→6%。内訳: 指名PU 0.7% / 過去フェス限+同時PU 0.9% を
  対象9名で等分(0.1%/人) / その他恒常 4.4%。
- 平常PUも0.7%。1連=120石。

## 初回PUボーナスと文字(エレフ)経済

- 指名PUの自引き、または呼出ポイント交換での初確保 → 100文字ボーナス。
  すり抜け(0.9%枠)での初獲得はボーナスなし(素体のみ)。
- 重複: すり抜け重複=30文字+50欠片 / PU重複(ボーナス消費済)=100文字+50欠片 /
  PU重複(未消費)=100+100文字+50欠片。
- 欠片→文字の交換段階: 20@1:1, 20@1:2, 20@1:3, 20@1:4、以降5欠片=1文字。
- 神名文字コスト累計: 星4=100 / 固有1=220 / 固有2=340 / 固有3=520 / 固有4=720。

## 呼出チャージ(新仕様)の天井

- チャージ99で次の1連が50%、199で100%。指名を引くと0にリセット。
- 募集の種別ごとに引き継ぐ: 恒常→恒常、フェス限/限定→フェス限/限定。
- 99連仕込み: フェス期間に99まで貯めて止め、次の限定をチャージ99で開始する運用。
  貯金中に指名を引くと崩れる(保持率 0.993^99 ≒ 49.89%)。199まで伸ばすのは
  暴発率が高く非実用。

## 呼出ポイント(旧仕様)

- 200連ごとに200ptで任意のPU生徒1名と交換できる(交換でも初回100文字が付く)。

## 5.5周年の登場生徒

- PU指名可能4名: 水着イブキ(新)、水着イロハ(新)、制服ネル(復刻)、リオ(復刻)。
- すり抜けプール9名 = 新旧フェス限10名 − 指名中の1名。
  過去8名: クロコ、臨戦ホシノ、制服ネル、リオ、水着ミカ、水着ナギサ、臨戦アリス、ケイ。

数値の再計算は不要 — `node bin/festival-numbers.js`(リポジトリ内)が正準値を出す。
