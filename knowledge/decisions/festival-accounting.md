# ユーザー裁定(2026-07 のレビューサイクルで確定)

以下は全てユーザー(ベテランのブルアカプレイヤー)の指示・訂正による確定ルール。
再計算や記事改稿のときに勝手に変えてはならない。

## 補填(副産物)の会計 — 10連価値ルール

- 平常ガチャの10連 = 50欠片 ≒ 10文字 → **1.0文字/連**
- フェス期間の10連 = 80欠片 ≒ 16文字 → **1.6文字/連**
- これが唯一の公認副産物会計。星3出現率×欠片のようなアドホック計算は却下済み。
- 掘り効率: 素の200文字/90.07連 = 2.2204文字/連。補填込みで平常掘り 3.2204、
  フェス限掘り 3.8204 文字/連。
- 対称性: 旧仕様(呼出ポイント)側の追加連にも同じフェス副産物1.6文字/連を計上する。
  片側だけ補填すると不公平(ユーザー明言)。

## 戦略の定義

- **イロハ連打(focus)**: 機械的な床。(狙う人数−1)×200連まで早抜けせず引き切る。
  「制服ネル交換して終わる」ような趣旨違いの抜け道は例外として除外済み。
- **PU切替(sequential)**: 200連での早抜けを狙う生存戦略。期待獲得文字を減らしてでも
  石を残し「明日のガチャの蓄え」を遺す。最初の完了ブロックで即降りる。
- 交換(200pt)は未所持の他生徒を優先。本人交換は最終保険。
- フェス限を取り逃す選択肢はなし(全構成で完走前提)。

## 結論の締め方

- 見出しを「石で選ぶなら」にしない(「選べねえよ！」と炎上する、ユーザー指摘)。
  「8,108石安くなる代わりに115文字減少」型で、浮いた石を200文字掘りにぶつけて
  何文字取り返せるかを衝突させた数字が結論。
- **最終結論: 「文字目的の90連が残っているか否かで天地が分かれる」**
  - 掘り先あり → ほぼ全構成で新仕様(呼出チャージ)優位: 2PU +38 / 3PU +84・+12 /
    4PU +145・早抜けのみ −16
  - 掘り先なし → 石を文字に戻せず全構成で旧仕様(呼出ポイント)優位
- イロハ連打の限界効率は補填込み3.11文字/連 < 基準3.82。どちらの世界でも
  連打は信仰するほどの打ち方ではない、と結論づける(ユーザー承認)。

## 表現ルール

- 「持ち帰る文字」ではなく「獲得文字」に統一。
- 比較表は無条件平均(0ベース)ではなく、離脱ブロック別の条件付き行で示し、
  各コホートが持つ文字を行ごとに運ぶ。
- タブごとの結論(verdict)はタブ直下に置き、戦略2行(3PU/4PUは連打と切替)をぶつける。
