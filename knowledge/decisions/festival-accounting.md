# ユーザー裁定(2026-07 のレビューサイクルで確定)

以下は全てユーザー(ベテランのブルアカプレイヤー)の指示・訂正による確定ルール。
再計算や記事改稿のときに勝手に変えてはならない。

## 補填(副産物)の会計 — 10連価値ルール

- 平常ガチャの10連 = 50欠片 ≒ 10文字 → **1.0文字/連**
- フェス期間の10連 = 80欠片 ≒ 16文字 → **1.6文字/連**
- これが唯一の公認副産物会計。星3出現率×欠片のようなアドホック計算は却下済み。
- 掘り効率: 素の200文字/90.07連 = 2.2204文字/連。補填込みで平常掘り 3.2204、
  フェス限掘り 3.8204 文字/連。
- 対称性: 旧仕様(呼び出しポイント)側の追加連にも同じフェス副産物1.6文字/連を計上する。
  片側だけ補填すると不公平(ユーザー明言)。

## 戦略の定義

- **イロハ連打(focus)**: 機械的な床。(狙う人数−1)×200連まで早抜けせず引き切る。
  「制服ネル交換して終わる」ような趣旨違いの抜け道は例外として除外済み。
  (2026-07-28 裁定) 効率の悪い文字周回にしかならない**検討の余地がない悪手**。
  タブ直下のverdictの比較相手には使わない(3PU/4PUはsequentialと比較)。
  結論表には従来どおり載せ、表の後の〆で「実は水着イロハを引き続ける行為は、
  文字目的のPU募集よりも効率が悪い方法という事が判明した」とさらっと雑魚扱いする。
- **PU切替(sequential)**: 200連での早抜けを狙う生存戦略。期待獲得文字を減らしてでも
  石を残し「明日のガチャの蓄え」を遺す。最初の完了ブロックで即降りる。
- 交換(200pt)は未所持の他生徒を優先。本人交換は最終保険。
- フェス限を取り逃す選択肢はなし(全構成で完走前提)。

## 結論の締め方 (2026-07-28 改定)

- 見出しを「石で選ぶなら」にしない(「選べねえよ！」と炎上する、ユーザー指摘)。
- ページ末尾の「まとめ」節は置かない。まとめと結論が分かれると
  「詐欺まがいの契約書」になる(ユーザー指摘)。結論はタブ直下のverdictのみ。
- verdictは3行固定:
  1. 「呼び出しチャージは〈青:8,108石〉安くなる代わりに〈赤:220文字分減少〉。」
  2. 「文字目的の周回 〈下線+ツールチップ:67.6連〉 → 218文字」
     (ツールチップ: `67.6連 * 50欠片 / 5文字 + 200文字 / 期待値90連`)
     周回換算は**平常時の10連50欠片**で行う(banking.chaseRate=3.22文字/連)。
     フェス80欠片換算は使わない(2026-07-28 ユーザー裁定)。
  3. 優位側を色分け: 周回回収≥減少なら青「呼び出しチャージ優位」、
     下回るなら赤「呼び出しポイント優位」。50欠片換算では全構成で赤
     (2PU 218<220 / 3PU 183<205 / 4PU 173<221)。
- 訪問者は文章を読みに来ていない。どれだけ得か損かの数字だけを求めている。
- 「呼び出しポイントは200連単位でしか降りられない」とは書かない。
  200連で降りない前提はユーザーが指定した想定であり、仕様ではない。

## 表現ルール

- 「持ち帰る文字」ではなく「獲得文字」に統一。
- 比較表は無条件平均(0ベース)ではなく、離脱ブロック別の条件付き行で示し、
  各コホートが持つ文字を行ごとに運ぶ。
- タブごとの結論(verdict)はタブ直下に置き、戦略2行(3PU/4PUは連打と切替)をぶつける。
