網羅性と再現方法

  • calculate.js は、各募集前の「獲得済み人数 × チャージ（0〜199）」を状態として、成功・失敗の両方へ確率質量を分配します。
  • チャージ99では成功率50%、199では100%、その他では0.7%。成功時は次のPUへ進みチャージ0、失敗時はチャージを1増やします。
  • 独立に求めた「1人を引くまでの所要回数分布」を2回畳み込む別計算とも照合しています。最大差は 3.331e-16、確率質量の最大誤差は 2.442e-15 でした。
  • node calculate.js で results.json とこのHTMLを再生成できます。JSONには1〜300連の全行と、1人目を引いた個々の回（1連目、2連目…）ごとの寄与を収録しています。
